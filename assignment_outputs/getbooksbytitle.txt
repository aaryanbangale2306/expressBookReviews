Task Name: Task 5 - getbooksbytitle

Exact Command Used:
curl -s "http://localhost:5000/title/Things%20Fall%20Apart"

Short Explanation:
This command performs an HTTP GET request to '/title/Things%20Fall%20Apart'. It verifies that the server extracts the URL-encoded title parameter, accurately searches through the books database by title, and returns the matching book record with its details.
