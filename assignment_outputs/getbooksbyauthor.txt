Task Name: Task 4 - getbooksbyauthor

Exact Command Used:

{

Short Explanation:
This command performs an HTTP GET request to '/author/Jane%20Austen'. It demonstrates proper handling of URL-encoded parameter spaces, case-insensitive author filtering across the dataset, and successful retrieval of all books authored by Jane Austen.
